## 🚀 Projetos em destaque

### 🤟 [Librando](https://www.librandotcc.com.br/) — plataforma de ensino de Libras
Plataforma educacional com atividades progressivas para aprender letras e sinais básicos de Libras, inspirada na experiência de apps como o Duolingo. Tem identidade visual própria, com a mascote **Lili**, um elefante roxo.

- Interface interativa de aprendizagem com JavaScript e componentes web
- Dados estruturados com Firebase/Firestore
- Pesquisa de reconhecimento e correção de gestos com Python e MediaPipe
- 🏆 Reconhecido como melhor TCC de 2025

`JavaScript` `Firebase` `Python` `MediaPipe` · [🌐 Site](https://www.librandotcc.com.br/) · [📁 Repositório](https://github.com/JoaoRacero0805/Librando)

`Python` `IA` `RAG`
